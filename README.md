# PSU Phuket CWIE Dashboard — v3

เว็บไซต์ HTML/CSS/JavaScript แบบ Static รองรับ GitHub Pages

## 4 หน้า
- `index.html` — ข้อมูลองค์กรภาครัฐ (95 รายการ / 210 นักศึกษา)
- `international.html` — หน่วยงานต่างประเทศ (73 รายการ / 69 นักศึกษา)
- `positions.html` — สถานประกอบการคู่ความร่วมมือ 55 แห่ง จัดหมวด 8 อุตสาหกรรม
- `mou-status.html` — ตารางตรวจสอบสถานะการฝึกงาน 55 แห่ง (ไม่มีการเดายอดนักศึกษา)

## วิธีติดตั้ง GitHub Pages
1. แตก ZIP แล้วเปิดโฟลเดอร์ PSU_Phuket_CWIE_Dashboard_v3
2. อัปโหลดไฟล์ **ด้านใน** ทุกไฟล์ไปไว้ที่ root ของ GitHub Repository (Public)
3. Settings → Pages → Deploy from a branch → main / (root) → Save
4. เข้า URL ที่ GitHub Pages แสดงไว้

เว็บไซต์โหลดกราฟจาก Chart.js CDN และโหลดฟอนต์จาก Google Fonts จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อแสดงกราฟและฟอนต์ครบถ้วน

## Data note
- 55 แห่งจากชีต 'ข้อมูลตำแหน่งฝึกงานขององค์กรคู่' เท่านั้น
- 60 รายการในชีต Job Fair 2026 เป็นข้อมูลคนละชุดและไม่ถูกรวม
- 8 หมวดอุตสาหกรรมจาก PDF หน้า 28–29; บริษัทถูกจับคู่จากค่า Type ใน Excel
- iCONEXT ไม่มีค่า Type ในต้นฉบับ แต่จัดเทคโนโลยีตามประเภทธุรกิจที่เห็นได้ชัดจากชื่อบริษัทและงาน Software Developer/Programmer; ตรวจสอบกับผู้ดูแลข้อมูลก่อนใช้เป็นรายงานอย่างเป็นทางการ
- ใน Excel 55 แห่ง ไม่มีบริษัท Education & Training ที่ยืนยันได้ จึงแสดง 0 ในหมวดนี้
- เนื่องจากรายการบริษัทใน PDF ไม่ตรงกับ Excel 55 รายการทั้งหมด เว็บไซต์ไม่อ้างว่าเป็นการจับคู่รายบริษัทจาก PDF ทุกแถว
- ตัวเลขตำแหน่งนับบรรทัดตำแหน่งที่ไม่ว่างในไฟล์ ตำแหน่งบางบรรทัดมีหลายหน้าที่ ไม่ควรตีความเป็นจำนวนรับสมัคร
- ช่องว่างจำนวน นศ. ในต่างประเทศถูกนับเป็น 0 เฉพาะกราฟ/ยอดรวม โดยยังเก็บข้อมูลต้นทางใน data.js เป็น 0
- รายชื่อ/ตำแหน่งเป็นข้อมูลทางประวัติ ไม่ยืนยันว่ามีเปิดรับในปัจจุบัน

## การติดตามจำนวนผู้เข้าฝึกในองค์กร MOU
ข้อมูลปัจจุบันไม่ครอบคลุมประวัติการฝึกงานในภาคเอกชน จึงยังยืนยันยอดนักศึกษาราย MOU ไม่ได้ เว็บไซต์แสดง 55 แห่งในสถานะรอตรวจสอบ ไม่ใช่ 0 นักศึกษา สามารถ Export CSV เพื่อนำไปกรอกชื่อคู่สัญญาภาษาไทยและจำนวนจากเอกสารอ้างอิง แล้วนำไปเชื่อมข้อมูลในรุ่นต่อไป
